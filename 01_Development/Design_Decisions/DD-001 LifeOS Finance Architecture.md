# DD-001 Finance Data Model（Simplified）

## Summary

LifeOS 財務模組的核心不是打造另一套記帳
App，而是**幫助使用者理解自己的財務狀態**。

核心資料模型：

-   **Facts**：財務事實
-   **Intentions**：人生規劃
-   **Insights**：系統洞察

------------------------------------------------------------------------

## Problem

整理財務時，我們發現真正缺少的不是記錄，而是理解。

因此，LifeOS 將設計方向由：

**記錄交易 → 理解財務**

------------------------------------------------------------------------

## Decision

採用三層資料模型：

``` text
Facts
   ↓
Intentions
   ↓
Insights
```

-   Facts：描述客觀事實
-   Intentions：描述資金用途與人生規劃
-   Insights：由系統自動產生分析與洞察

------------------------------------------------------------------------

## Options

  方案                     結果   原因
  ------------------------ ------ --------------------------
  用途直接決定資產／負債   ❌     混淆用途與財務本質
  資產／負債與用途分離     ✅     保持資料一致性與可擴充性

------------------------------------------------------------------------

## Data Model

``` text
Facts
├─ Accounts
├─ Assets
├─ Liabilities
└─ Amount

↓

Intentions
├─ Purpose
├─ Goal
├─ Priority
└─ Tags

↓

Insights
├─ Total Assets
├─ Net Worth
├─ Available Funds
└─ Future Analysis
```

------------------------------------------------------------------------

## Available Funds

不是：

> 帳戶裡有多少錢

而是：

> 真正可以自由決策的資金

``` text
Available Funds
=
可動用資產
－ 已預留用途資金
－ 已形成付款義務
```

------------------------------------------------------------------------

## Consequences

所有未來財務功能皆遵循：

``` text
Facts
   ↓
Intentions
   ↓
Insights
```

不得跨層修改資料定義。

------------------------------------------------------------------------

## Philosophy

> 使用者輸入的是生活，
>
> **LifeOS 輸出的是理解。**

**Facts + Intentions → Insights**
